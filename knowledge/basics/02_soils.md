「何の汚れか」を見分けられれば、使う洗剤は前の章の考え方から自動的に決まります。ただし、素材ごとの NG（素材別の章）と製品のラベルの方が優先です。

## 汚れの表

| 汚れ | 正体 | 落とし方 | 注意 |
|---|---|---|---|
| ほこり・砂・毛 | 乾いた粒 | 掃除機、ドライシート、粘着ローラー。濡らすのは最後 | 先に水をかけると泥になって溝に入る |
| 手あか・皮脂 | 油 + タンパク質 + ほこり | 中性〜弱アルカリ性（セスキ水）+ ぬるま湯で拭く | 放っておくと黄ばみ、ベタつく |
| 新しい食用油 | 油 | 台所用中性洗剤 + 40℃ くらいの湯 | 冷えると固まって落ちにくい |
| 古い油（換気扇） | 固まった油 + ほこり | 弱アルカリ〜アルカリ性 + 温度 + つけ置き。最後に中性で洗い流す | 中性では落ちない。アルミの部品にアルカリは NG |
| 焦げ | 炭になった食べ物 | 重曹や酸素系漂白剤 + 加熱 + 時間、そのあと軽くこする | こするだけだと傷になる。ホーローは特に |
| 血・卵・牛乳・汗じみ | タンパク質 | **水〜ぬるま湯** + 酵素入り洗剤でつけ置き | 50℃ 以上の湯で固まる |
| ご飯・パスタ・糊 | でんぷん | 水にひたして柔らかくする | 乾いたら時間をかけて戻す |
| 水垢 | カルシウムなど | クエン酸 + 湿布の時間 | 白くて酸で溶けないタイプ（シリカ）は研磨で削る。石材・金属に酸は NG |
| 石けんカス | 石けん + 皮脂 | 酸で溶かす、または弱アルカリ + 洗剤。交互に使う。**混ぜない** | 浴室の白いザラザラの主な原因 |
| 尿石 | カルシウムなど | 酸性トイレ洗剤 + 時間 + ブラシ | 塩素系と同時に使うと有毒ガス |
| カビ（黒・ピンク） | 菌 | 塩素系漂白剤 + 時間。予防は換気・乾燥・栄養（石けんカス・皮脂）を無くす | 根が深いと色が残る。ゴムには湿布 |
| さび | 鉄のさび | クエン酸、還元系漂白剤、研磨 | もらいさびは早めに。ステンレスは塩素系が原因になることも |
| 茶渋・コーヒー | 色素 | 酸素系漂白剤 + 温水、または塩素系。重曹でこすっても可 | 傷のあるプラスチックには染み込む |
| 黄ばみ（衣類） | 皮脂が酸化したもの | 弱アルカリ洗剤 + 40℃ + 酸素系漂白剤 | しまう前に洗い残しを作らない |
| 臭い | 菌が出す物質 | 原因（皮脂・食べかす・水分）を取り除く。換気と乾燥 | 芳香剤で隠しても原因は残る |
| ガム・接着剤・ワックス | 樹脂やゴム | アルコールやベンジンで溶かす。ガムは冷やして固めて剥がす | 溶剤はプラスチックや塗装を傷める |
| テレビ裏のほこり | 静電気で付いた粉 | 乾いたマイクロファイバー | 濡らすと筋になる |

## 見分けのヒント

- 白くてザラザラで、クエン酸をかけても変わらない → 酸で溶けない水垢（削る）
- クエン酸で溶ける → ふつうの水垢
- 触るとベタつく → 油（アルカリか洗剤）
- 水で拭くと一度消えて、乾くとまた出る → 水垢か石けんカス
- 黒い点が広がる、ぬめりがある → カビや菌
- 茶色〜黄色で、漂白剤で薄くなる → 色素の汚れ

## 「落ちない」のよくある原因

| 状況 | 足りなかったもの |
|---|---|
| 中性洗剤でこすっても換気扇の油が落ちない | アルカリと温度 |
| 血のしみを熱湯で洗ってしまった | 温度が高すぎた（固まった） |
| 鏡の水垢にクエン酸をかけてすぐ流した | 時間（湿布） |
| 浴室の白い汚れに酸をかけたら一部だけ落ちた | 石けんカスの油の部分が残っている（次はアルカリ） |
| 床をいきなり水拭きして筋が残る | 先に乾いたほこりを取る手順 |
| 塩素系でカビは消えたのに数日で戻る | 湿気と換気が変わっていない |
