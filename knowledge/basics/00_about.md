## なにが書いてあるか

掃除・洗濯の「なぜそうするのか」をまとめた教科書です。元の資料は法律や公的機関、メーカーの説明書を根拠にして書かれています。ここではその内容を、専門用語をなるべく使わずに言い直しています。

数字や決まりごとを正確に確かめたいときは、各章の最後にある「くわしい元の資料」を開いてください。

## 読む順番

1. **汚れを落とす 4 つの力** — 洗剤・こする・温度・時間の掛け算だと知る
2. **汚れの見分け方** — 目の前の汚れが何でできているかを見る
3. **洗剤の種類とラベルの読み方** — ラベルを読めば広告に頼らなくていい
4. **安全** — 混ぜてはいけない組み合わせを覚える
5. **素材別の OK と NG** — 素材を傷めないための表
6. **除菌・消毒**、**洗濯** — 目的に合わせて

## 覚えておく言葉（5 つだけ）

| 言葉 | 意味 |
|---|---|
| 洗剤 | 主に「水と油をなじませる成分」の力で汚れを落とすもの。台所用・洗濯用など |
| 洗浄剤 | 主に「酸・アルカリ・漂白の化学の力」で落とすもの。浴室用・トイレ用・カビ取り用など |
| 液性 | 酸性か、中性か、アルカリ性か。ラベルに必ず書いてある |
| 除菌と消毒 | 「消毒」は薬として認められた製品だけが使える言葉。「除菌」はそれ以外。効き目の強さの順ではない |
| 洗濯表示 | 「ここまでの強さなら大丈夫」という上限を示す。表示より弱く洗うのは自由 |

## 情報の信じ方

元の資料では、情報を「科学 → 法律・規格 → 公的機関 → 業界団体 → メーカーの説明書 → ブログや動画」の順に信頼しています。ブログや動画は参考にはしても、根拠にはしません。

製品ごとの「これに使っていいか」は、その製品の取扱説明書がいちばん強い根拠です。一般的な表より説明書を優先してください。
