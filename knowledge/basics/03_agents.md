## 「洗剤」と「洗浄剤」は別のもの

日本の家庭用洗剤の名前と表示は、法律（家庭用品品質表示法）で決まっています。ラベルは法律に基づく情報なので、読めるようになると広告に頼らずに選べます。

| 名前 | 何の力で落とすか | 例 |
|---|---|---|
| 洗剤 | 水と油をなじませる成分の力 | 洗濯用・台所用の洗剤、石けん |
| 洗浄剤 | 酸・アルカリ・漂白の化学の力 | 浴室用、トイレ用、カビ取り用、換気扇レンジ用 |
| 漂白剤 | 色素や菌を壊す | 塩素系、酸素系、還元系 |
| 磨き剤 | 削って落とす | クレンザー |

住宅用の洗浄剤は「浴室用洗浄剤」のように用途を名前に付ける決まりで、「万能洗剤」という名前は認められていません。

## ラベルで見る 6 か所

| 項目 | 見方 |
|---|---|
| 品名 | 「洗濯用合成洗剤」「浴室用洗浄剤」など法律で決まった呼び方 |
| 用途 | 使っていい対象。ここに書いていない場所に使うのは自己責任 |
| 液性 | 酸性 / 弱酸性 / 中性 / 弱アルカリ性 / アルカリ性 |
| 成分 | 主成分の種類と割合。酵素や漂白剤が入っていれば必ず書いてある |
| 使用量の目安 | メーカーが効き目を保証する量。多く入れても効き目は頭打ちで、すすぎ残りが増えるだけ |
| まぜるな危険 | 酸性か塩素系で、混ぜると塩素ガスが出る製品には表示の義務がある |

## 家でよく使う剤の早見表

| 剤 | 液性 | 得意 | 苦手・使ってはいけない |
|---|---|---|---|
| 台所用中性洗剤 | 中性 | 日常の油、皮脂、食器 | 固まった油、水垢 |
| 洗濯用洗剤（粉） | 弱アルカリ性 | 皮脂、泥、汗 | ウール・シルク（傷む） |
| 洗濯用洗剤（液体） | 中性〜弱アルカリ性 | 日常の衣類 | 粉より力は控えめ |
| 重曹 | 弱アルカリ性（弱い） | 軽い油、消臭、やさしい研磨 | 強い油汚れ。アルミが黒くなる |
| セスキ炭酸ソーダ | 弱アルカリ性（重曹より強い） | 手あか、皮脂、中くらいまでの油 | 水垢。畳や木の変色 |
| 炭酸ソーダ | アルカリ性 | 重い油、煮洗い | 手荒れ、アルミ、塗装面 |
| クエン酸 | 酸性 | 水垢、石けんカス、尿石、電気ポットの白い汚れ | 大理石、コンクリート、鉄・銅。**塩素系と混ぜない** |
| 塩素系漂白剤 | アルカリ性（強い） | カビ、色素、除菌 | 色柄物、ウール・シルク、金属（さびる）、木。**酸と混ぜない**。換気必須 |
| 酸素系漂白剤（粉） | 弱アルカリ性 | 茶渋、色柄物の漂白、洗濯槽、黄ばみ | ウール・シルク。密閉した容器に入れない（ガスで膨らむ） |
| 酸素系漂白剤（液体） | 弱酸性 | 色柄物、ウール・シルクの部分漂白 | 粉より弱い |
| クレンザー | 中性〜弱アルカリ性 | 焦げ、こびりつき | 傷（プラスチック、鏡面、ホーロー、フッ素加工） |
| アルコール | — | 油膜、除菌、すぐ乾く | プラスチックが白くなる、塗装、革。火のそばで使わない |
| メラミンスポンジ | — | 水垢、手あか（削って落とす） | 光沢面、コーティング、鏡面に傷 |

## 「使用量の目安」を守る理由

洗剤の効き目は、決まった試験方法で「目安の量」を使って測られています。倍入れても効き目は倍になりません。すすぎ残りが増えて、肌への刺激や再汚染の原因になります。

## 選び方の 5 ステップ

1. 汚れの性質を見分ける（酸性 / アルカリ性 / 乾いた粒 / 菌）
2. 素材の NG を確認する（素材別の章）
3. いちばん弱い液性から試す（中性 → 弱アルカリか弱酸 → アルカリか酸 → 漂白剤）
4. 落ちなければ、強い薬剤より先に温度と時間を足す
5. 使ったらすすぐか水拭きする。酸・アルカリ・塩素系は特に残さない
