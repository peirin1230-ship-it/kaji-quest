## 混ぜてはいけない組み合わせ

| 組み合わせ | 何が起きるか |
|---|---|
| **塩素系（カビ取り剤、ハイターなど）× 酸性のもの**（クエン酸、酢、酸性トイレ洗剤、酸性の水垢取り） | **有毒な塩素ガス**。閉め切った浴室やトイレで死亡事故が起きている |
| 塩素系 × アンモニアを含む製品（一部のガラスクリーナーなど） | 刺激のあるガス |
| 塩素系 × アルコール | 有害な物質ができることがある |
| 塩素系 × 酸素系漂白剤 | 急にガスが出て、効き目も打ち消し合う |
| 塩素系 × 熱湯 | 分解が進んで塩素の臭いが強くなる。ぬるま湯まで |
| 酸 × 金属（鉄・アルミ・銅） | 水素が出て、金属が腐食する |
| 酸素系漂白剤を密閉した容器に長く入れる | 酸素で容器が膨らんで破裂する |

原則は「同じ場所で使うなら、間にたっぷり水で流す」です。浴室では石けんカス（アルカリで落とす）と水垢（酸で落とす）が混ざっているので、交互に使いたくなります。必ず間に水を流すか、日を分けてください。

## 使うときの基本

- **換気**: 塩素系・酸性・アルカリ性・溶剤は、窓を開けて換気扇を回す。浴室ならドアを開け、閉め切って作業しない
- **手袋**: アルカリ性と塩素系は皮膚を溶かす。目の保護も、スプレーは特に
- **上に向けて吹かない**: 天井のカビは布に含ませて塗る。液だれが目に入る
- **原液で長く放置しない**: ラベルの放置時間の上限を守る
- **目に入った、皮膚についた**: すぐに流水で 15 分以上洗い、製品を持って受診する
- **飲み込んだ**: 無理に吐かせない（塩素系・酸・アルカリは吐くと食道をもう一度傷める）。中毒 110 番へ
- **保管**: 子どもの手の届かない場所。飲み物の容器に移し替えない。直射日光と高温を避ける

## 素材を壊す組み合わせ

| 剤 | 使ってはいけない素材 |
|---|---|
| 酸（クエン酸、酸性洗浄剤） | 大理石、コンクリート、セメントの目地、鉄、銅、真鍮、アルミ |
| アルカリ（セスキ、炭酸ソーダ、アルカリ電解水） | アルミ（黒くなる）、塗装面、ワックスの床、木や畳（変色）、ガラスに長時間（白くにごる） |
| 塩素系 | 金属全般（ステンレスもさびる）、木、色柄物、革、大理石 |
| 溶剤・アルコール | 透明なプラスチック（白くなる、割れる）、塗装面、革、ニス |
| 研磨（クレンザー、メラミン） | 光沢面、鏡面ステンレス、コーティング、フッ素加工、透明プラスチック |
| 大量の水 | 無垢材やオイル仕上げの木、電気製品、畳 |

くわしくは「素材別の OK と NG」の章へ。
