# 05 除菌・消毒

家庭で「除菌」と書かれた製品は多いですが、公的に**濃度と条件つきで有効性が評価された方法**は限られています。ここではそれだけを載せます。

## 1. 用語（薬機法上の整理）

| 語 | 意味 | 使われる製品 |
|---|---|---|
| 滅菌 | すべての微生物を殺滅・除去 | 医療器具 |
| 消毒 | 病原微生物を害のない程度まで減らす | 医薬品・医薬部外品（承認が必要） |
| 除菌 | 菌・ウイルスの数を減らす。「消毒」の語は使えないが実際に無毒化できる製品もある | 洗剤・漂白剤など雑品 |
| 抗菌 | 菌の増殖を抑える（表面加工など） | 雑品 |
| 殺菌 | 菌を殺す（程度を問わない） | 医薬品・医薬部外品 |

## 2. 大前提：先に洗浄、それから消毒

汚れ（有機物）が残っていると、次亜塩素酸ナトリウムもアルコールも消費・妨害されて効かなくなります。
**汚れを落とす → 水分を拭く → 消毒剤を作用させる → 必要なら拭き取る**の順。

## 3. 公的に評価された「モノ」の消毒・除菌方法

厚生労働省・経済産業省・消費者庁の特設ページ（NITEの有効性評価に基づく。新型コロナウイルスを対象）。

| 方法 | 条件 | 家庭での実際 | 注意 |
|---|---|---|---|
| 熱水 | **80℃で10分間**さらす | 食器・箸・まな板・ふきん | やけど。耐熱でない樹脂 |
| 塩素系漂白剤 | **次亜塩素酸ナトリウム 0.05%以上**で拭き、その後水拭き | ドアノブ、手すり、便座、テーブル | 金属腐食、変色、換気、手袋。手指には使わない |
| アルコール | **エタノール 60〜95%** | ドアノブ、スイッチ、スマホ（メーカー可否確認） | 引火。樹脂の白化 |
| 家庭用洗剤（界面活性剤） | 下記9種が使用時に所定濃度以上含まれる製品で拭き、水拭き | 台所用・住宅用洗剤で日常清掃と兼ねる | 製品リスト（NITE）は2021年10月で更新停止。成分表示で確認 |
| 次亜塩素酸水 | 拭き掃除は**有効塩素濃度80ppm以上**（ジクロロイソシアヌル酸Naを溶かしたものは100ppm以上）。汚れがひどい場合は200ppm以上。流水で掛け流す場合は35ppm以上 | 市販品は濃度表示・製造日を確認 | 光・熱で分解しやすく保管に弱い。**次亜塩素酸ナトリウムとは別物** |

有効とされた界面活性剤（使用時濃度）：

| 界面活性剤 | 濃度 |
|---|---|
| 直鎖アルキルベンゼンスルホン酸ナトリウム | 0.1%以上 |
| アルキルグリコシド | 0.1%以上 |
| アルキルアミンオキシド | 0.05%以上 |
| 塩化ベンザルコニウム | 0.05%以上 |
| 塩化ベンゼトニウム | 0.05%以上 |
| 塩化ジアルキルジメチルアンモニウム | 0.01%以上 |
| ポリオキシエチレンアルキルエーテル | 0.2%以上 |
| 純石けん分（脂肪酸カリウム） | 0.24%以上 |
| 純石けん分（脂肪酸ナトリウム） | 0.22%以上 |

※この評価は「モノ」の表面が対象で、手指・皮膚・空間噴霧は対象外。空間噴霧は推奨されていません。

## 4. 次亜塩素酸ナトリウムの希釈

家庭用塩素系漂白剤の次亜塩素酸ナトリウム濃度は製品ラベルで確認（多くは5〜6%）。**濃度が製品ごとに違うので、必ずラベルの数値で計算**。

| 目的 | 目標濃度 | 5%製品からの目安 |
|---|---|---|
| 日常のモノの消毒（新型コロナ対応） | 0.05%（500ppm） | 水1Lに10mL |
| ノロウイルス：便・嘔吐物が付いた場所 | 0.1%（1000ppm） | 水1Lに20mL |
| ノロウイルス：日常の環境表面 | 0.02%（200ppm） | 水1Lに4mL |

- 希釈液はその日のうちに使い切る（分解する）。
- 金属は腐食するので作用後に水拭き。
- 手袋・換気。酸性の製品と絶対に混ぜない（[04_safety.md](04_safety.md)）。

## 5. 目的別メモ

### ノロウイルス（冬の胃腸炎）
- **アルコールが効きにくい**ため、塩素系または加熱が基本（厚労省ノロウイルスQ&A）。
- 嘔吐物処理：使い捨て手袋・マスク、ペーパーで外側から内側へ包み取り、0.1%次亜塩素酸Naで浸すように拭き、その後水拭き。処理者の手洗い。
- 調理器具は洗浄後、85℃以上で1分以上の加熱、または塩素系で消毒。

### 食中毒予防（厚労省「家庭でできる食中毒予防」）
- 「つけない・増やさない・やっつける」の3原則。まな板・ふきんは洗浄→熱水または塩素系。
- 生肉を扱った後の手・器具は都度洗浄。

### 手指
- 石けんでの手洗い＋流水でのすすぎが基本。厚労省はハンドソープで10秒もみ洗い→流水15秒すすぎでウイルス残存が1万分の1程度になるデータを紹介している。
- 手指用のアルコール（医薬品・医薬部外品）はモノ用の評価とは別枠。

### カビ
- 生育条件は**温度（20〜30℃）・湿度（概ね70%以上）・栄養（皮脂・石けんカス・ほこり）**。三つのうち湿度と栄養を家庭で管理する。
- 殺菌・漂白は塩素系（次亜塩素酸Na）＋時間。予防は入浴後の換気・水気の拭き取り・石けんカス除去。

### 洗濯槽・排水口
- ぬめり（バイオフィルム）は物理的除去＋塩素系または酸素系。定期（月1目安）は各洗濯機メーカーの取説が最上流。

## 6. やらない方がよいこと（公的資料で推奨されない）

- 空間への消毒剤噴霧（人がいる空間）
- 次亜塩素酸水の効果を「次亜塩素酸ナトリウム」と混同する
- 汚れたままの表面にアルコールを吹く（有機物で失活）
- 消毒剤の手指使用（手指用に承認された製品を除く）
