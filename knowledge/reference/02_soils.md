# 02 汚れの分類と落とし方

「何の汚れか」を見分けられれば、洗剤選びは [01_principles.md](01_principles.md) の原理から自動的に決まります。
この表は**一般則**です。素材ごとの禁止事項（[07_surfaces.md](07_surfaces.md)）と製品ラベルが優先します。

## 汚れの対応表

| 汚れ | 主成分 | 性質 | 有効なアプローチ（化学／機械力／温度／時間） | 落ちにくくなる原因・注意 |
|---|---|---|---|---|
| ほこり・砂・毛 | 繊維くず、砂、皮膚片、花粉 | 固体粒子 | 乾式（掃除機・ドライシート・粘着）。湿らせるのは最後 | 先に水を使うと泥化して繊維や目地に入り込む |
| 手あか・皮脂 | 脂質＋タンパク＋ほこり | 酸性（油性） | 中性〜弱アルカリ性洗剤＋ぬるま湯＋布で拭く。セスキ炭酸ソーダ水が定番 | 放置で酸化して黄ばみ・粘着化 |
| 食用油（新しい） | トリグリセリド | 酸性（油性） | 界面活性剤（台所用中性洗剤）＋40℃前後の湯 | 冷えると固まり乳化しにくい |
| 食用油（古い・換気扇） | 酸化・重合した油＋ほこり | 酸性（油性・固化） | 弱アルカリ〜アルカリ性洗浄剤＋温度＋つけ置き時間。最後に中性で洗い流す | 樹脂化した油は中性では落ちない。アルミ部品にアルカリは禁忌 |
| 焦げ付き | 炭化した有機物 | 固着 | アルカリ（重曹・過炭酸Na）＋加熱＋時間 → 研磨。ホーローは研磨傷に注意 | 機械力だけで削ると素材に傷 |
| タンパク質 | 血液、卵、牛乳、汗じみ | 熱で凝固 | **水〜ぬるま湯**＋酵素（プロテアーゼ）配合洗剤。つけ置き | 50℃以上の湯で固定される |
| でんぷん | ご飯、パスタ、糊 | 水で膨潤 | 水につけて膨潤させる＋アミラーゼ酵素 | 乾燥固化したら時間（水に浸す） |
| 水あか | 炭酸カルシウム、マグネシウム塩、シリカ | アルカリ性（無機） | 酸（クエン酸水、酸性洗浄剤）＋湿布時間。シリカ主体の鱗状痕は酸に溶けにくく研磨（酸化セリウム等）が必要 | 蛇口・鏡に何層にも堆積すると時間が必要。石材・金属に酸は禁忌 |
| 石けんカス | 脂肪酸カルシウム（金属石けん）＋皮脂 | 複合 | 酸で金属分を溶かす、または弱アルカリ＋界面活性剤で脂肪分を落とす。両方が混ざるため交互に（**混ぜない**） | 浴室の白いざらつきの主因 |
| 尿石 | リン酸カルシウム、尿酸塩など | アルカリ性（無機） | 酸性トイレ用洗浄剤＋時間＋ブラシ | 塩素系との併用は塩素ガス（[04_safety.md](04_safety.md)） |
| カビ（黒カビ・赤カビ） | 真菌（Cladosporium、Rhodotorula 等）と代謝物 | 生物 | 塩素系漂白剤（次亜塩素酸Na）で殺菌・漂白＋時間。予防は換気・乾燥・栄養（石けんカス・皮脂）除去 | 深く根を張ると色素が残る。ゴムパッキンは湿布 |
| さび | 酸化鉄 | 無機 | 酸（クエン酸、還元系漂白剤）または研磨 | もらいさびは早期対応。ステンレスは塩素系が原因になりうる |
| 茶渋・コーヒー | ポリフェノール類の着色 | 有機着色 | 酸素系漂白剤（過炭酸Na）＋温水、または塩素系。研磨剤（重曹）でも可 | 傷のある樹脂には染み込む |
| 黄ばみ（衣類） | 皮脂の酸化物 | 酸性 | 弱アルカリ洗剤＋40℃＋酸素系漂白剤 | 長期保管前に洗い残しを作らない |
| 臭い | 菌の代謝物、アミン類、硫黄化合物 | 混合 | 原因物（皮脂・食品残渣・水分）を除去。換気・乾燥。塩素系・酸素系で菌を減らす | 芳香剤でマスクしても原因は残る |
| ワックス・ガム・接着剤 | 樹脂、ゴム | 油性・固着 | 溶剤（エタノール、ベンジン）、冷却して硬化させ剥がす（ガム） | 溶剤は樹脂・塗装面を侵す |
| 静電気で付く粉塵（テレビ裏など） | ほこり | 固体粒子 | 乾式＋帯電防止（マイクロファイバー） | 湿式で拭くと筋になる |

## 見分け方のヒント

- **白くてざらざら、酸で泡立たない** → シリカ系水あか（研磨）／**酸で溶ける** → 炭酸カルシウム系水あか
- **触るとベタつく** → 油性（アルカリまたは界面活性剤）
- **水で拭くと一時的に消え、乾くと戻る** → 無機の堆積（水あか・石けんカス）
- **黒く点状で広がる、ぬめりがある** → 生物（カビ・バイオフィルム）
- **茶〜黄で、漂白剤で薄くなる** → 有機着色

## 家庭でよくある「落ちない」の原因分析

| 状況 | 見落としている要素 |
|---|---|
| 中性洗剤でこすっても換気扇の油が落ちない | 化学（アルカリ）と温度 |
| 血液のしみを熱湯で洗ってしまった | 温度（タンパク凝固） |
| 鏡の水あかにクエン酸をかけてすぐ流した | 時間（湿布） |
| 浴室の白い汚れに酸をかけたら一部だけ落ちた | 石けんカスの脂肪分（アルカリ側）が残っている |
| 床をいきなり水拭きして筋が残る | 乾式の省略 |
| 塩素系でカビは消えたが数日で再発 | 湿度・換気（生育条件）が変わっていない |
