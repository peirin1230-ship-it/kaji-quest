# 01 洗浄の原理

家庭の掃除も業務清掃も、原理は同じです。**汚れを対象物から引き離し、運び去り、再び付けない**こと。
この章は以降すべての章の土台になります。

## 1. ジンナーの円（Sinner's Circle）

1959年にヘンケル社の Herbert Sinner が家庭用洗濯機の研究で示した考え方。洗浄効果は次の4要素の**掛け算**で決まり、1つを減らしたら他の要素で補う必要がある、という整理です。

| 要素 | 家庭での具体例 | 増やすと | 減らすと |
|---|---|---|---|
| 化学（Chemical） | 洗剤の種類・濃度・pH、漂白剤、酵素 | 素材・環境負荷が増える | 他の3要素で補う |
| 機械力（Mechanical） | こする、ブラシ、水流、高圧、拭き取り | 素材の傷・摩耗 | 時間か化学で補う |
| 温度（Temperature） | 湯、スチーム、温めた洗浄液 | 油が溶け反応が速い。タンパクは固まる | 時間・化学で補う |
| 時間（Time） | つけ置き、放置（湿布） | 素材への薬剤影響 | 化学・機械力で補う |

使い方の例：
- 換気扇の油汚れ：**温度**（40〜50℃の湯）と**時間**（つけ置き）を増やせば、**化学**（強いアルカリ）と**機械力**（ゴシゴシ）を減らせる。
- 大理石など酸に弱い素材：**化学**を弱くせざるを得ないので、**時間**と**機械力**（柔らかいパッド）で補う。
- 洗濯の水温を下げる（節電）：**時間**を延ばすか、**化学**（洗剤量・酵素）で補う。

> 家庭で「ゴシゴシこすって傷をつける」失敗の多くは、化学・温度・時間を使わずに機械力だけで解こうとした結果と説明できます。

## 2. 汚れが落ちる仕組み

### 2.1 汚れの三態

| 分類 | 例 | 主な落とし方 |
|---|---|---|
| 固体粒子 | ほこり、砂、すす、花粉 | **乾式**で除去（掃除機・ドライシート・はたき）。先に水を使うと泥化して広がる |
| 油性汚れ | 皮脂、食用油、ワックス、化粧品 | 界面活性剤で乳化、アルカリでけん化、温度で軟化、溶剤で溶解 |
| 水溶性汚れ | 塩、糖、尿、汗の一部 | 水で溶かす。乾燥固化したものは時間（湿らせる）を使う |

実際の汚れは混合物（皮脂＋ほこり＝手あか、油＋ほこり＝換気扇のベタつき）なので、**固体粒子を先に乾式で除去し、次に油性・水溶性を湿式で落とす**のが基本順序です。

### 2.2 界面活性剤の働き

界面活性剤は1分子の中に水になじむ部分（親水基）と油になじむ部分（疎水基）を持ち、水と油の境界（界面）の性質を変えます。洗浄では次の4作用で整理されます（日本石鹸洗剤工業会などの標準的な説明）。

1. **浸透作用** — 表面張力を下げ、洗浄液を繊維や汚れの隙間に入り込ませる
2. **乳化作用** — 油を細かい粒にして水中に混ぜる
3. **分散作用** — 固体粒子をばらばらにして水中に浮かせる
4. **再付着防止作用** — 離れた汚れが対象物に戻るのを防ぐ

種類（親水基の電荷による分類）：

| 分類 | 代表例 | 特徴・用途 |
|---|---|---|
| 陰イオン（アニオン） | 石けん（脂肪酸Na/K）、直鎖アルキルベンゼンスルホン酸Na（LAS）、アルキルエーテル硫酸エステルNa（AES） | 洗浄力が高く泡立つ。洗濯・台所用の主力 |
| 非イオン（ノニオン） | ポリオキシエチレンアルキルエーテル（AE）、アルキルグリコシド（APG） | 泡が少なめ、硬水に強い、油に強い。液体洗剤の主力 |
| 陽イオン（カチオン） | 塩化ベンザルコニウムなどの第4級アンモニウム塩、柔軟剤成分 | 負に帯電した繊維・菌に吸着。柔軟・除菌・帯電防止。陰イオンと混ぜると打ち消し合う |
| 両性 | アルキルアミンオキシド、ベタイン | 低刺激、増粘・泡質改善 |

### 2.3 pH（液性）と汚れの中和

家庭用品品質表示法（雑貨工業品品質表示規程）による液性の区分。液状品は原液、それ以外は使用適量の最高濃度溶液を25℃で測定（JIS Z 8802）。

| 表示 | pH |
|---|---|
| 酸性 | 3.0 未満 |
| 弱酸性 | 3.0 以上 6.0 未満 |
| 中性 | 6.0 以上 8.0 以下 |
| 弱アルカリ性 | 8.0 超 11.0 以下 |
| アルカリ性 | 11.0 超 |

汚れとの対応の基本則：

| 汚れの性質 | 例 | 対応する液性 | 理由 |
|---|---|---|---|
| 酸性の汚れ | 油、皮脂、手あか、食べこぼし | **アルカリ性** | 油脂をけん化・タンパクを分解 |
| アルカリ性の汚れ | 水あか（炭酸カルシウム）、石けんカス、尿石、白い粉ふき | **酸性** | 炭酸塩・リン酸塩を溶かす |
| どちらでもない軽い汚れ | 日常のほこり＋薄い皮脂 | 中性 | 素材への影響が最小 |

中性洗剤は「素材を傷めにくい代わりに化学の力が弱い」ので、ジンナーの円で言えば機械力・温度・時間で補う設計です。

### 2.4 温度

- 油脂は温度が上がると粘度が下がり、界面活性剤に乳化されやすくなる（多くの動物性脂の融点は 30〜45℃）。
- 化学反応の速度は温度で上がる（アルカリによる油のけん化、漂白剤の酸化）。
- **タンパク質は熱で変性・凝固して落ちにくくなる**（血液、卵、牛乳）。タンパク汚れは水〜ぬるま湯から始める。
- 洗剤配合の酵素（プロテアーゼ：タンパク、リパーゼ：脂質、アミラーゼ：でんぷん、セルラーゼ：セルロース）は一般に 30〜40℃前後で働きやすく、高温で失活する。

### 2.5 機械力

こする・叩く・水流・吸引。効くが、素材の**硬度差**が傷を作る（研磨剤より柔らかい素材に研磨剤を使えば傷がつく）。素材別の限界は [07_surfaces.md](07_surfaces.md)。

### 2.6 時間

汚れは時間とともに落ちにくくなる（油の酸化・重合、水あかの結晶成長、カビの根の侵入）。逆に薬剤は時間を与えると少ない機械力で効く（つけ置き、ペーパーやラップでの湿布）。**放置時間の上限は素材と製品ラベルが決める**。

### 2.7 水質（硬度）

水中のカルシウム・マグネシウムイオンは石けんと結合して「石けんカス（金属石けん）」を作り、洗浄力を落とし、浴室の白い汚れの一因になります。合成洗剤には硬度成分を捕まえる成分（キレート剤、ゼオライト）が配合されています。日本の水道水は多くの地域で硬度が低め（軟水寄り）ですが、地域差があります。

## 3. 洗浄力はどう測られているか

JIS K 3362「家庭用合成洗剤試験方法」（原案作成：日本石鹸洗剤工業会、2024年改正）では、人工汚染布（洗濯科学協会が頒布）を洗浄試験機で洗い、洗浄前後の表面反射率から洗浄率を求めます。

```
洗浄率 D(%) = (Rw − Rs) / (Ro − Rs) × 100
  Ro：白布の反射率  Rs：汚染布の洗浄前反射率  Rw：洗浄後反射率
```

「落ちる」という表現には、こうした定量的な裏付けの世界があることを知っておくと、広告の「〇倍落ちる」を条件付きで読めるようになります。

## 4. 実務の基本順序（ビルクリーニングの慣行）

1. **乾式 → 湿式**（ほこりを先に取る）
2. **上 → 下**（落ちたほこりを最後に床で回収）
3. **奥 → 手前 / 出口へ**（きれいにした所を踏まない）
4. **弱い薬剤 → 強い薬剤**（中性で試し、落ちなければ液性を寄せる）
5. **目立たない所で試す**（変色・白化のテスト）
6. **薬剤を残さない**（すすぐ／水拭き。残留は素材劣化と再汚染の原因）
7. **乾かして終わる**（水分はカビ・水あか・臭いの原因）
