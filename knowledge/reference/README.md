### 書くときのルール

1. 断定する記述には Tier 0〜4 の出典を付ける（ファイル末尾の「出典」節、または行内の `[出典: …]`）。
2. 濃度・温度・pH・時間などの**数値は出典と条件**（対象、濃度、測定条件）を併記する。
3. 製品固有の可否（この床材にこの洗剤は使えるか等）は、その製品の取扱説明書・SDSを最上流とし、一般則より優先する。
4. 二次情報しか見つからない知見は行頭に `⚠要検証` を付け、根拠が見つかったら外す。
5. URLは変わるので、**文書名・発行機関・確認日**もあわせて残す（[99_sources.md](99_sources.md) 参照）。
6. 「効く」「落ちる」などの効果主張は、条件（汚れ・素材・温度・時間）を限定して書く。

## 読む順番（初学者向け）

1. `01_principles.md` — 洗浄は「化学 × 機械力 × 温度 × 時間」の掛け算だと理解する
2. `02_soils.md` — 目の前の汚れが何でできているかを見分ける
3. `03_agents.md` — 洗剤のラベルを読めるようになる
4. `04_safety.md` — やってはいけない組み合わせを覚える
5. `07_surfaces.md` — 素材を傷めないための可否
6. `05_hygiene.md` / `06_laundry.md` — 目的別

## 用語集（最小限）

| 用語 | 意味 | 根拠 |
|---|---|---|
| 洗剤 | 主な洗浄作用が界面活性剤の働きによるもの | 家庭用品品質表示法（NITE解説） |
| 洗浄剤 | 主な洗浄作用が酸・アルカリ・酸化剤の化学作用によるもの | 同上 |
| 液性 | 製品のpH区分（酸性／弱酸性／中性／弱アルカリ性／アルカリ性） | 雑貨工業品品質表示規程 |
| 界面活性剤 | 親水基と疎水基を持ち、界面の性質を変える物質 | 界面化学 |
| 消毒／除菌 | 「消毒」は医薬品・医薬部外品に使われる語、「除菌」は主にそれ以外の製品で菌・ウイルスを減らす意 | 厚労省 特設ページ |
| 上限情報 | 洗濯表示は「回復不可能な損傷を起こさない最も厳しい処理」を示す | JIS L 0001（消費者庁解説） |
