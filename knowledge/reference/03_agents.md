# 03 洗剤・洗浄剤の分類とラベルの読み方

日本の家庭用洗剤の「名前」と「表示」は、**家庭用品品質表示法**（消費者庁所管）とその下位規程（雑貨工業品品質表示規程）で決まっています。
つまりラベルは法律に基づく一次情報です。読めるようになると、広告に頼らず製品を選べます。

## 1. 法律上の分類

| 用語 | 定義（要約） | 例 |
|---|---|---|
| **洗剤** | 主な洗浄作用が**界面活性剤の働き**によるもの | 洗濯用・台所用の合成洗剤、石けん |
| **洗浄剤** | 主な洗浄作用が**酸・アルカリ・酸化剤の化学作用**によるもの | 浴室用・トイレ用・カビ取り用・換気扇レンジ用洗浄剤 |
| 漂白剤 | 衣料用、台所用、住宅用 | 塩素系、酸素系、還元系 |
| 磨き剤 | 台所用、住宅用、家具用 | クレンザー |

洗濯用・台所用の「洗剤」は界面活性剤の内訳でさらに区分されます。

| 区分 | 純石けん分（脂肪酸Na／K）の割合 |
|---|---|
| 石けん | 界面活性剤が純石けん分のみ |
| 複合石けん | 純石けん分が主体で、合成界面活性剤を一部含む（洗濯用は合成分30%以下、台所用は40%以下） |
| 合成洗剤 | 純石けん分以外の界面活性剤が主体（洗濯用は30%超、台所用は40%超） |

住宅用・家具用の洗浄剤の品名には、必ず「洗浄剤」の語を付け、用途を表す（例：「浴室用洗浄剤」「カビ取り用洗浄剤」）。「万能洗剤」のような表現は品名として認められていません。

## 2. ラベルの読み方（表示事項）

| 項目 | 読み方 |
|---|---|
| **品名** | 「洗濯用合成洗剤」「台所用石けん」「浴室用洗浄剤」など法定の用語 |
| **用途** | 使える対象。ここに書かれていない対象への使用は自己責任 |
| **液性** | 酸性／弱酸性／中性／弱アルカリ性／アルカリ性（pH区分は [01_principles.md](01_principles.md)） |
| **成分** | 界面活性剤は「含有率（％）」と「種類名」を表示。洗浄補助剤・添加剤は1%以上で機能名、10%以上で種類名も。蛍光増白剤・酵素・漂白剤は含有率に関係なく表示 |
| **正味量** | 容量 |
| **使用量の目安** | メーカーが性能を保証する濃度。多く入れても性能は頭打ちで、すすぎ残りが増える |
| **使用上の注意** | 素材の禁止、保護具、換気 |
| **まぜるな危険** | 酸性タイプまたは塩素系で、所定試験で塩素ガス1.0ppm以上を発生する製品に表示義務。枠囲い・文字サイズまで規定 |

成分欄の界面活性剤名の読み方（主なもの）：

| 表示名 | 分類 | 主な用途 |
|---|---|---|
| 純石けん分（脂肪酸ナトリウム／カリウム） | 陰イオン | 石けん |
| 直鎖アルキルベンゼンスルホン酸ナトリウム（LAS） | 陰イオン | 洗濯用・台所用 |
| アルキルエーテル硫酸エステルナトリウム（AES） | 陰イオン | 台所用・シャンプー |
| アルファオレフィンスルホン酸ナトリウム（AOS） | 陰イオン | 台所用 |
| ポリオキシエチレンアルキルエーテル（AE） | 非イオン | 液体洗濯用 |
| アルキルグリコシド（APG） | 非イオン | 台所用・住宅用 |
| アルキルアミンオキシド | 両性 | 台所用（泡・粘度） |
| 塩化ベンザルコニウム、第4級アンモニウム塩 | 陽イオン | 除菌剤・柔軟剤 |

## 3. 家庭でよく使う剤の早見表

pHは「1％程度の水溶液・室温」での目安で、濃度・温度で変わります。製品の液性表示が優先。

| 剤 | 主成分 | 液性（目安pH） | 得意な汚れ | 苦手・禁忌 |
|---|---|---|---|---|
| 台所用中性洗剤 | LAS、AES、AE、アミンオキシド | 中性（6〜8） | 日常の油、皮脂、食器 | 固化した油、水あか |
| 洗濯用洗剤（粉末） | LAS、炭酸塩、ゼオライト、酵素 | 弱アルカリ性（9〜11） | 皮脂、泥、汗 | 毛・絹（アルカリで傷む） |
| 洗濯用洗剤（液体） | AE、LAS、酵素 | 中性〜弱アルカリ性 | 日常の衣類汚れ | 粉末より洗浄力は控えめ（学内試験で約10%差の報告） |
| 重曹（炭酸水素ナトリウム） | NaHCO₃ | 弱アルカリ性（約8.3） | 軽い油、消臭、穏やかな研磨 | 強い油汚れ。アルミの黒変 |
| セスキ炭酸ソーダ | Na₂CO₃·NaHCO₃ | 弱アルカリ性（約9.8） | 手あか、皮脂、軽〜中程度の油 | 水あか。畳・木の変色 |
| 炭酸ソーダ（炭酸ナトリウム） | Na₂CO₃ | アルカリ性（約11） | 重い油、煮洗い | 手荒れ、アルミ、塗装面 |
| クエン酸 | C₆H₈O₇ | 酸性（約2） | 水あか、石けんカス、尿石、電気ポットの湯あか | 大理石・コンクリート・金属（鉄、銅）。**塩素系と混ぜない** |
| 塩素系漂白剤 | 次亜塩素酸ナトリウム（家庭用は概ね5〜6%）、水酸化Na | アルカリ性（12〜13） | カビ、着色、除菌（0.05%希釈で消毒用途） | 色柄物、毛・絹、金属（さび）、木部の変色。**酸と混ぜない**。換気必須 |
| 酸素系漂白剤（粉末） | 過炭酸ナトリウム | 弱アルカリ性（約10.5） | 茶渋、色柄物の漂白、洗濯槽、黄ばみ | 毛・絹、金属容器での長時間保管（酸素発生・密閉厳禁） |
| 酸素系漂白剤（液体） | 過酸化水素 | 弱酸性 | 色柄物、毛・絹の部分漂白 | 粉末より弱い |
| クレンザー | 炭酸カルシウム、ケイ酸塩＋界面活性剤 | 中性〜弱アルカリ性 | 焦げ、こびりつき | 傷（樹脂、鏡面、ホーロー、フッ素加工） |
| アルコール（エタノール） | エタノール 60〜95% | — | 油膜、除菌、乾きの速さ | 樹脂の白化、塗装、革。引火 |
| メラミンスポンジ | メラミン樹脂（研磨） | — | 水あか、手あか（研磨で削る） | 光沢面・コーティング・鏡面に傷 |

## 4. 「使用量の目安」を守る根拠

洗剤性能は JIS K 3362 の試験方法（人工汚染布・洗浄試験機）などで、**標準使用量**で評価されています。倍量入れても洗浄率は比例して上がらず、すすぎ残り（皮膚刺激・再汚染・排水負荷）が増える、というのが業界・行政側の説明です。

## 5. 選び方のフロー

1. 汚れの性質を [02_soils.md](02_soils.md) で判定（酸性／アルカリ性／固体／生物）
2. 素材の禁忌を [07_surfaces.md](07_surfaces.md) で確認
3. 最も**弱い液性**から試す（中性 → 弱アルカリ／弱酸 → アルカリ／酸 → 酸化剤）
4. 落ちなければ薬剤ではなく**温度・時間**を先に足す
5. 使ったら**すすぐ・水拭き**。特に酸・アルカリ・塩素系は残さない
