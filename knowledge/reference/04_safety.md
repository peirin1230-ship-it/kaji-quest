# 04 安全

清掃の事故は「混ぜる」「密閉空間で使う」「素材を壊す」「子どもが飲む」の4つにほぼ集約されます。

## 1. 混ぜてはいけない組み合わせ

| 組み合わせ | 何が起きるか | 根拠の位置づけ |
|---|---|---|
| **塩素系（次亜塩素酸Na）× 酸性タイプ**（クエン酸、酢、酸性トイレ用洗浄剤、酸性の水あか取り） | **塩素ガス**発生。浴室・トイレの密閉空間で死亡事故の原因 | 家庭用品品質表示法で「まぜるな危険」表示義務（所定試験で塩素ガス1.0ppm以上発生する製品） |
| 塩素系 × アンモニアを含む製品（一部のガラスクリーナー等） | クロラミン類（刺激性ガス） | 一般化学 |
| 塩素系 × アルコール | 有害な有機塩素化合物が生じうる | 一般化学（併用しない） |
| 塩素系 × 酸素系漂白剤 | 塩素・酸素の急激な発生、効果の打ち消し | 一般化学 |
| 塩素系 × 熱湯 | 分解が進み塩素臭が強まる。ぬるま湯まで | 製品ラベル |
| 酸 × 金属（鉄・アルミ・銅） | 水素発生・腐食 | 一般化学 |
| 酸素系漂白剤（過炭酸Na）を密閉容器で長時間 | 酸素で容器が膨張・破裂 | 製品ラベル（密閉厳禁） |

原則：**「連続して使わない」ではなく「同じ場所で使うなら間に十分な水流し」**。石けんカス（アルカリ側）と水あか（酸側）の混在した浴室で交互に使う場合が典型。

## 2. 使うときの基本

- **換気**：塩素系・酸性・アルカリ性・溶剤は窓開け＋換気扇。浴室ならドアを開け、密閉状態で作業しない。
- **保護具**：ゴム手袋（アルカリ・塩素系は皮膚のタンパクを溶かす）、目の保護（飛散しやすいスプレーは特に）、マスク。
- **上向きスプレー禁止**：天井のカビは布に含ませて塗る。液だれ・目への落下を防ぐ。
- **原液で長時間放置しない**：ラベルの放置時間上限を守る。素材劣化とガス発生。
- **目に入った／皮膚についた**：直ちに流水で15分以上洗い流し、製品を持って受診（製品ラベル・SDSの応急措置に従う）。
- **飲み込んだ**：無理に吐かせない（塩素系・酸・アルカリは吐かせると再び食道を傷める）。日本中毒情報センターへ。
- **保管**：子どもの手の届かない場所、飲料容器への移し替え禁止、直射日光・高温を避ける（塩素系は分解して効力低下）。

## 4. 素材を壊す組み合わせ（詳細は 07_surfaces.md）

| 剤 | 使ってはいけない主な素材 |
|---|---|
| 酸（クエン酸、酸性洗浄剤） | 大理石・石灰岩・コンクリート・セメント目地、鉄、銅、真鍮、アルミ |
| アルカリ（セスキ、炭酸ソーダ、アルカリ電解水） | アルミ（黒変）、塗装面・ワックス面、木・畳（変色）、ガラスの長時間放置（白濁） |
| 塩素系 | ステンレスを含む金属（さび・孔食）、木部、色柄物、革、大理石 |
| 溶剤・アルコール | アクリル・ポリスチレン等の樹脂（白化・割れ）、塗装面、革、ニス |
| 研磨剤（クレンザー・メラミン） | 光沢面、鏡面ステンレス、コーティング、フッ素樹脂、透明樹脂 |
| 水（大量） | 無垢・オイル仕上げの木、電気製品、畳 |

## 5. 法令

- **家庭用品品質表示法**（消費者庁）— 表示義務、「まぜるな危険」
- **有害物質を含有する家庭用品の規制に関する法律（家庭用品規制法）**（厚生労働省）— 家庭用品中の有害物質（ホルムアルデヒド等）の基準
- **化学物質排出把握管理促進法（化管法）SDS制度**（経産省・厚労省・環境省）— 業務用製品のSDS交付。家庭用製品でもメーカーがSDSを公開している場合が多く、成分・危険有害性・応急措置の一次情報になる
